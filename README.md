# Stacja uzdatniania wody – AVEVA InTouch

Projekt interfejsu HMI/SCADA dla stacji uzdatniania wody. Projekt w pełni funkcjonalny, jednak ze względu na brak dostępu do sterownika i licencji przedstawione są jedynie zrzuty ekranu.

## Ekran logowania
Ekran startowy aplikacji z przyciskiem logowania.

![Ekran logowania](Screenshot_1.jpg)

## Ekran główny
Schemat technologiczny stacji z pomiarami ciśnienia, przepływu
i poziomu cieczy oraz panelem sterowania symulacją.

![Ekran główny](Screenshot_2.jpg)

## Parametry technologiczne
Panel nastaw sprężarek, pomp sieciowych, poziomów cieczy
w zbiornikach oraz czasów płukania filtrów.

![Parametry technologiczne](Screenshot_3.jpg)
